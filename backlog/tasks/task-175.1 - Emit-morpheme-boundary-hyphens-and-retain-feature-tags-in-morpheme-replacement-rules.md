## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Morpheme replacement rules generated by `parc_macros/generate_morpheme_replace_rules.py` currently erase all feature tags and emit raw strings without boundary indicators. To provide anchors and boundary segmentation for structured intermediate export, update the generator to retain the primary feature tag and add boundary hyphens `-` according to slot role (e.g., prefix `[Pro=1sg]tsi-`, suffix `-[Aspect=Present]ih`, `-[Tense=Present]a`). Also ensure `-` is included in the phonological alphabet so it is accepted as a valid symbol.
<!-- SECTION:DESCRIPTION:END -->
